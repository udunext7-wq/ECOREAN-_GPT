# RC-0.3.0 사용자 테스트 가이드

## 목적

RC-0.3.0이 실제 운영 흐름에서 사용할 수 있는지 확인한다.

## 테스트 진입

앱에서 `RC-0.3.0 사용자 테스트`를 열고 새 회차를 시작한다.

- 버전: `RC-0.3.0`
- 시나리오: `전체 사용자 테스트`
- 환경: `Windows Desktop / Local DB`

## 필수 테스트

1. 욕실 단독 리모델링 견적 생성
2. 주방 리모델링 견적 생성
3. 전체 리모델링 견적 생성
4. LightBIM JSON 가져오기
5. 수량 검토 및 사용자 수정
6. 견적 계산 및 PCE 확인
7. 계약서, 공정표, 발주서 생성
8. 자재입고와 실행 피드백 입력
9. LightBIM 추적 보기와 내부 공간 맵 확인
10. 고객용 공간 제안 맵 확인
11. 디자인 보드 / 제안서 PDF payload 확인
12. 고객 포털 안전성 확인

## 고객 안전성 확인

고객 화면에는 아래 정보가 나오면 안 된다.

- 원가
- 마진
- PCE
- 협력업체 단가
- 노무비
- 발주 / 입고
- 실제 사용량
- 차이율
- 보정 룰
- 내부 위험 알림

## 판정 기준

- `실사용 가능`: S1/S2 이슈가 없고 12단계가 모두 통과
- `조건부 사용 가능`: S3 이하만 남고 우회 방법이 있음
- `수정 후 재검토`: S2가 남아 있음
- `사용 보류`: S1이 남아 있음

상세 기준은 `docs/RC_0_3_0_ACCEPTANCE_CRITERIA.md`를 따른다.
