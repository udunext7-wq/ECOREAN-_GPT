# Estimate vs Actual Report Rules

## Purpose

This report compares expected estimate values with actual project results.

It creates correction candidates, not direct Master DB changes.

## Comparison Areas

- cost
- duration
- materials
- labor
- subcontract
- equipment
- waste
- transport
- missing processes
- unnecessary processes
- supplier issues
- defect issues

## Output

The output may create recommendedMasterDbUpdates, but all updates must go through Master DB Update Request and Approval Log.
