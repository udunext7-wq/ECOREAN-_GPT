# RC-0.3.0 실제 단가 보정 가이드

## 왜 실제 단가 보정이 필요한가

RC-0.3.0 초기 기준 데이터는 견적을 시작하기 위한 기본값이다.
초기 단가는 외부 시장 가격으로 검증된 값이 아니며, 실제 업체 견적, 매입가, 노무 단가로 교체해야 한다.

실제 단가 보정 흐름:

입력 → 차이 비교 → 승인 → 백업 → 마스터 반영 → 다음 견적 적용

## 우선 입력할 단가

가장 먼저 확인할 항목:

- 욕실 타일
- 타일 부자재
- 방수
- 도기
- 수전
- 주방 가구
- 상판
- 바닥재
- 도배
- 목공
- 전기
- 노무 단가
- 철거 / 폐기물
- 표준 견적 필수 항목

## 업체 견적 단가 입력 방법

1. `실제 단가 보정` 화면을 연다.
2. 대상 유형을 `MATERIAL` 또는 `STANDARD_ITEM`으로 입력한다.
3. 항목 ID 또는 항목명을 입력한다.
4. 업체명, 견적 단가, 단위, 증빙 메모를 입력한다.
5. `업체 견적 입력`을 누른다.
6. 항목은 `PENDING_REVIEW` 상태로 승인 대기에 들어간다.

## 실제 매입 단가 입력 방법

1. 실제 발주/입고 또는 영수증 기준의 매입 단가를 확인한다.
2. 항목명, 실제 매입 단가, 업체명, 단위, 비고를 입력한다.
3. `실제 매입 단가 입력`을 누른다.
4. 기존 단가와 제안 단가의 차이가 자동 계산된다.
5. 자재 단가 이력에도 기록된다.

## 노무 단가 입력 방법

1. 대상 역할 또는 labor ID를 입력한다.
2. 기존 일당과 제안 일당을 확인한다.
3. `노무 단가 입력`을 누른다.
4. 승인 후 반영하면 `labor_master`의 기본 일당이 갱신된다.

## 승인 / 반영 절차

단가 입력만으로 마스터 데이터는 변경되지 않는다.

1. Queue 항목을 검토한다.
2. `승인` 또는 `반려`를 선택한다.
3. 승인된 항목만 `백업 후 반영`할 수 있다.
4. 반영 전 자동 백업이 생성된다.
5. 마스터 데이터 가격과 `price_status`가 갱신된다.
6. `real_price_update_history`에 old/new 가격이 기록된다.

## 백업 후 반영 원칙

단가 반영 전에는 반드시 백업이 필요하다.

백업 실패 시:

- 기본 동작은 반영 중단
- 화면 메시지: `백업 실패로 단가 반영을 중단했습니다.`

## 견적 반영 확인 방법

1. 단가를 승인 후 반영한다.
2. `기준 데이터 관리`에서 price_status가 `CONFIRMED`인지 확인한다.
3. 욕실/주방/전체 리모델링 위저드를 열어 내부 견적의 Master Data 상태를 확인한다.
4. PCE 결과가 정상 생성되는지 확인한다.

## 주의사항

- 외부 가격 크롤링은 포함하지 않는다.
- 입력 가격은 사용자가 확인한 가격이며 시장 검증 가격으로 자동 보증되지 않는다.
- 고객 화면에는 업체 견적, 내부 단가, 노무 단가, 단가 차이, 승인 이력을 표시하지 않는다.
- 확정 단가를 변경할 때도 승인과 백업이 필요하다.
