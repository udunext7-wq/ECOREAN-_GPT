# NEEDS_CONFIRMATION Display Rules

목적: 불확실한 공정을 자동 포함하지 않고, 대표 또는 담당자가 확인해야 할 질문으로 표시한다.

## 표시 위치

- New Estimate Wizard 결과 영역
- Estimate Preview
- Schedule Draft Preview의 차단 조건
- Approval Required Queue
- 내부 원가표 초안

## 필수 표시 필드

- itemId
- 질문
- 영향 공정
- 견적 영향
- 공정표 영향
- 발주 영향
- 고객 설명 가능 여부

## 예시

- 욕실 바닥 철거가 포함되는가?
- 방수층 손상이 확인되었는가?
- 창호 부분 교체 범위와 규격이 확정되었는가?
- 주방 가구는 전체 교체인가?
- 발코니 확장 또는 단열 보강이 있는가?
