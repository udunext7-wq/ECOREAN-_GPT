# Vendor Verification Checklist

목적: Vendor Candidate를 Verified Vendor로 전환하기 전에 반드시 확인해야 할 기준을 정의한다.

## 검증 상태

- `NOT_CONTACTED`: 아직 연락하지 않음
- `CONTACTED`: 1차 연락 완료
- `PRICE_RECEIVED`: 공급가 또는 견적 자료 수령
- `NEEDS_SECOND_CONTACT`: 추가 확인 필요
- `VERIFIED`: 거래 가능 조건 확인 완료
- `REJECTED`: 거래 부적합
- `PARTNER_CANDIDATE`: 장기 파트너 후보
- `BLACKLIST_CANDIDATE`: 거래 위험 후보

## 공통 검증 항목

| 항목 | 통과 기준 | 실패 기준 |
|---|---|---|
| 실제 영업 여부 | 대표 전화 또는 공식 채널 응답 | 연락 불가, 폐업 의심 |
| 취급 품목 | ECOREAN 공정 DB와 연결 가능 | 품목 불명확 |
| 실제 공급가 | 품목/규격/단위 기준으로 제시 | 단가 공개 거부 또는 소비자가만 안내 |
| 최소 발주 | 최소 수량/금액/배송 조건 확인 | 조건 불명확 |
| 납기 | 일반/긴급 납기 구분 가능 | 납기 책임 회피 |
| 결제 조건 | 현금, 카드, 월말 정산, 세금계산서 가능 여부 확인 | 세금계산서 불가 또는 조건 불명확 |
| 하자 책임 | 제품/시공/운송 파손 책임 구분 가능 | 하자 책임 회피 |
| A/S 주체 | 업체, 브랜드, 시공팀 중 책임 주체 명확 | A/S 주체 불명확 |
| 반복 거래 가능성 | 담당자/견적 프로세스/정산 방식 존재 | 매번 조건 변경 |

## VERIFIED 전환 기준

다음 조건을 모두 충족해야 한다.

1. 공식 또는 사업장 연락처로 실제 응답을 받았다.
2. 취급 품목과 브랜드가 확인되었다.
3. 최소 1개 이상 실제 공급가 또는 견적 가능 기준을 받았다.
4. 납기와 최소 발주 단위를 확인했다.
5. 결제 조건과 세금계산서 가능 여부를 확인했다.
6. 하자 발생 시 책임 범위를 확인했다.
7. Contact Log에 증빙 또는 요약 기록을 남겼다.
8. 대표 승인 후 Vendor Master 반영 대상으로 이동한다.

## PARTNER_CANDIDATE 기준

- 공급가가 경쟁력 있음
- 납기 응답이 빠름
- 월말 정산 또는 반복 거래 조건 협의 가능
- 하자/A/S 책임 범위가 명확함
- 담당자 응답이 안정적임
- ECOREAN 주요 공정과 반복 연결 가능

## BLACKLIST_CANDIDATE 기준

- 연락처 또는 사업장 정보가 불명확함
- 견적 후 가격을 반복 번복함
- 세금계산서 발행 불가
- 하자 책임을 회피함
- 납기 지연을 반복함
- 시공팀 또는 고객 클레임 이력이 누적됨

## Vendor Master 반영 흐름

Candidate DB  
→ 1차 연락  
→ Contact Log 기록  
→ 견적/조건 수령  
→ Verification Checklist 통과  
→ 대표 승인 요청  
→ `VERIFIED` 또는 `PARTNER_CANDIDATE` 전환  
→ Vendor Master 반영  
→ 공급가 변경은 Master DB Update Request로 별도 승인
