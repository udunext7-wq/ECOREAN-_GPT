# RC-0.3.1 운영 데이터 입력 가이드

## RC-0.3.0 기준선

RC-0.3.0은 `v0.3.0-rc` 태그로 고정된 운영 기준선입니다. 이 기준선은 LightBIM, 견적, PCE, 출력, 백업/복구, 초기 기준 데이터, 실제 단가 보정, 단가표 CSV 가져오기까지 검증된 상태입니다.

RC-0.3.1은 이 기준선을 바꾸지 않고 실제 운영 데이터를 넣으면서 마찰 지점을 기록하고 우선순위를 정리하는 단계입니다.

## 목적

RC-0.3.1 운영 데이터 입력 흐름은 다음 순서로 실제 운영 시작 준비를 기록합니다.

1. 전체 백업 생성
2. 초기 기준 데이터 상태 확인
3. 실제 업체 정보 입력
4. 자재 단가표 CSV 가져오기
5. 노무 단가표 CSV 가져오기
6. 단가 승인 및 Master Data 반영
7. 첫 실제 프로젝트 생성
8. LightBIM 도면 가져오기
9. 견적/PCE 확인
10. 고객용 견적서와 내부 원가표 출력 확인
11. 고객 화면 내부정보 비노출 확인
12. 문제 기록 및 RC-0.3.1 수정 후보 정리

## 운영 전 백업

실제 데이터 입력 전 반드시 백업 / 복구 센터에서 전체 백업을 생성합니다.

- DB 백업
- Export 폴더 백업
- 전체 userData 백업
- 현재 DB 무결성 검사

문제가 발생하면 백업 이력과 복구 계획을 먼저 확인합니다.

## 업체 정보 입력 순서

1. 기준 데이터 관리로 이동합니다.
2. 업체 마스터를 선택합니다.
3. 실제 업체명, 공정 범위, 연락처, 지역, 지급 조건을 입력합니다.
4. 저장 후 데이터 검증을 실행합니다.

## 자재 단가표 입력 순서

1. 단가표 일괄 가져오기로 이동합니다.
2. 가져오기 유형을 `자재 단가표` 또는 `업체 견적 단가표`로 선택합니다.
3. CSV 파일을 선택합니다.
4. 컬럼 매핑, 자동 매칭, 차이율을 확인합니다.
5. 정상 매칭 행만 승인 대기 큐로 생성합니다.

## 노무 단가표 입력 순서

1. 단가표 일괄 가져오기에서 `노무 단가표`를 선택합니다.
2. 역할, 단위, 일당 컬럼이 매핑되는지 확인합니다.
3. 실제 단가 보정 센터에서 승인 후 백업과 함께 반영합니다.

## 첫 프로젝트 생성

첫 실제 프로젝트에는 고객명, 현장명, 견적 유형, 공사 범위를 입력합니다. 실제 운영 전 테스트 프로젝트와 구분되는 이름을 사용하세요.

## LightBIM 도면 가져오기

1. LightBIM 도면 가져오기를 엽니다.
2. MiniCAD에서 내보낸 LightBIM JSON을 선택합니다.
3. 공간 수, 총 면적, 추천 견적 유형, 수량 요약을 확인합니다.
4. 견적 초안을 생성하고 수량 검토를 진행합니다.

## 견적/PCE 확인

업데이트된 실제 단가가 반영되는지 내부 견적에서 확인합니다. PCE 결과가 정상적으로 생성되는지 확인하고, 고객용 화면에는 내부 원가/마진/PCE가 노출되지 않아야 합니다.

## 고객용 출력 확인

고객용 견적서, 계약서, 고객 포털, 고객용 공간 제안 맵, 제안 보드에는 다음 정보가 표시되면 안 됩니다.

- internal cost
- margin
- PCE
- vendor data
- labor cost
- purchase data
- receiving data
- actual used quantity
- variance
- calibration
- backup paths
- onboarding issue details

## 오류 기록 방법

운영 데이터 입력 화면에서 단계별로 `단계 실패` 또는 `차단 기록`을 남기고 이슈를 추가합니다.

- S1: 앱 중단, 데이터 훼손, 고객 내부정보 노출
- S2: 단가 반영/견적/PCE/출력 흐름 차단
- S3: 혼동되는 UI, 약한 안내, 불편한 동선
- S4: 문구, 간격, 경미한 개선

S1/S2가 남아 있으면 운영 시작 가능으로 판정하지 않습니다.
