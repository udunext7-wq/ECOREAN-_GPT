# RC-0.3.0 운영 시작 체크리스트

RC-0.3.0은 운영 기준선으로 사용할 수 있는 상태까지 검증되었다. 실제 프로젝트 데이터를 입력하기 전 아래 항목을 순서대로 확인한다.

## 실행 전 준비

- [ ] 실행 PC가 Windows 데스크톱 앱 실행 환경을 만족하는지 확인
- [ ] 실행 파일 위치 확인
- [ ] GitHub 소스코드와 운영 데이터 저장 위치의 차이를 이해
- [ ] 실제 데이터 입력 전 테스트 데이터와 운영 데이터를 구분
