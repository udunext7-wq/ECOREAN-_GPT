# Completion Report Rules

## Purpose

The completion report stores final project results after handover.

It is the bridge from Project DB to Case Library.

## Must Record

- final contract amount
- additional work amount
- actual material cost
- actual labor cost
- actual subcontract cost
- actual equipment/waste/transport cost
- actual duration
- delay reasons
- defects and claims
- client feedback
- final margin
- lessons learned
- photos
- manager notes

## Rule

Completion report must be completed before the project can be used as INTERNAL_VALIDATED training data.
