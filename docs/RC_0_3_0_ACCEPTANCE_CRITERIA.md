# RC-0.3.0 Acceptance Criteria

## 출시 승인 기준

RC-0.3.0 사용자 테스트는 다음 조건을 모두 충족할 때 승인할 수 있다.

1. UT-01부터 UT-12까지 모든 단계가 실행되고 결과가 기록되어야 한다.
2. LightBIM JSON 가져오기부터 견적, PCE, 공정표, 발주, 실행 피드백, 고객 제안 출력까지 핵심 흐름이 차단 없이 완료되어야 한다.
3. 고객용 화면과 제안 보드에서 원가, 마진, PCE, 발주/입고, 실사용 차이, 내부 위험 정보가 노출되지 않아야 한다.
4. 고객 PDF 및 내부 출력 준비 상태가 확인되어야 한다.
5. `CRITICAL` 또는 `HIGH` 미해결 결함이 없어야 한다.
6. `npm run build:ui`, `npm run smoke:prod`, `npm run smoke:release`가 통과해야 한다.

## 보류 기준

- 하나 이상의 단계가 `BLOCKED`이다.
- 고객 안전 정보 차단 검증이 실패한다.
- 견적 또는 PCE 결과가 생성되지 않는다.
- 출력 파일이 열리지 않거나 주요 내용이 누락된다.

## 조건부 승인 기준

- 업무 흐름을 막지 않는 `LOW` 또는 `MEDIUM` 결함만 남아 있고, 후속 수정 일정과 담당자가 기록된 경우 검토할 수 있다.
