# RC-0.3.8 단가 미매칭 추천 센터 가이드

## 목적

단가표 가져오기 후 자동 매칭되지 않은 품목을 기존 Master Data와 비교해 후보 Top 3를 추천합니다. 추천은 대표 검토를 돕는 내부 정보이며 자동 승인, 자동 queue 반영, Master Data 직접 변경을 수행하지 않습니다.

## 추천 기준

추천 점수는 다음 기준을 합산합니다.

- 품목명 유사도
  - 공백, 괄호, 특수문자 제거
  - 영문 대소문자 정규화
  - 한글/영문 주요 품목 용어 정규화
  - 포함 관계와 문자열 bigram 유사도
- 분류 유사도
  - 자재 분류, 공정, 견적 유형 비교
- 단위 유사도
  - `EA`, `M`, `M2`, `M3`, `SET`, `식`, `품`, `일` 등 표준화
- 규격 유사도
  - 두께, 폭, 길이, 브랜드, 모델, 재질 토큰 비교
- 가격 범위 유사도
  - import 가격과 기존 Master Data 단가의 차이율
- 과거 이력
  - 동일 import 품목과 후보의 과거 승인 이력은 가점
  - 과거 반려 이력은 감점
  - 동일 공급처 반복은 보조 가점

## 신뢰도 의미

- `HIGH`: 점수 75 이상. Queue 연결 검토가 가능한 강한 후보입니다.
- `MEDIUM`: 점수 55 이상 75 미만. 대표 검토가 필요합니다.
- `LOW`: 점수 30 이상 55 미만. 참고 후보이며 규격과 단위를 다시 확인합니다.
- `NO_MATCH`: 점수 30 미만. 신규 Master Data 후보 검토가 필요합니다.

## 승인 / 반려 / 보류 기준

- 추천 승인
  - 품목, 단위, 규격, 가격 차이율과 점수 근거를 확인한 경우
  - 승인만으로 Master Data 가격은 변경되지 않습니다.
- 추천 반려
  - 다른 품목이거나 단위/규격이 잘못된 경우
  - 반려 이력은 다음 추천 점수에 반영됩니다.
- 추천 보류
  - 공급처, 규격, 단위 또는 가격을 추가로 확인해야 하는 경우

## Price Queue 연결 원칙

허용 상태 흐름:

`PENDING_REVIEW → APPROVED → LINKED_TO_QUEUE`

Queue ID를 입력하지 않으면 승인된 추천으로 `PENDING_REVIEW` queue를 새로 생성합니다. 기존 Queue ID를 입력하면 해당 queue의 존재를 확인한 뒤 연결합니다.

Queue 연결 후에도 다음 절차가 필요합니다.

`Real Price Calibration Workbench 승인 → 백업 → Master Data 반영 → old/new history`

추천 승인이나 queue 연결만으로 Master Data를 변경하지 않습니다.

## 신규 Master Data 검토 요청

다음 경우 `NO_MATCH`로 기록합니다.

- 모든 후보 점수가 30점 미만
- 대상 유형이 잘못되어 후보가 없는 경우
- 사용자가 신규 Master Data 검토를 명시적으로 요청한 경우

RC-0.3.8은 신규 Master Data를 자동 생성하지 않습니다.

## 고객용 출력 비노출

고객용 화면과 payload에는 다음 정보를 노출하지 않습니다.

- 미매칭 추천과 점수
- 신뢰도
- import row 단가
- 추천 Master Data 품목
- 현재/제안 단가와 차이율
- queue와 승인 상태
- 내부 원가, 마진, PCE
- 업체, 노무, 구매, 입고 정보
- 개인정보와 상세 주소

## 운영 순서

1. 단가표 일괄 가져오기에서 CSV를 미리보기하고 자동 매칭합니다.
2. 단가 미매칭 추천 센터를 엽니다.
3. 후보 Top 3와 점수 근거를 확인합니다.
4. 추천을 저장하고 승인, 반려 또는 보류합니다.
5. 승인된 추천만 Price Queue에 연결합니다.
6. 실제 단가 보정 워크벤치에서 다시 승인합니다.
7. 백업 성공 후에만 Master Data 가격을 반영합니다.

## 안정화 확인 기준

- 기준 fixture 점수는 `HIGH 93`, `MEDIUM 66`, `LOW 54`, `NO_MATCH 0`입니다.
- 추천 승인, 반려, 보류가 각각 독립 상태로 기록되어야 합니다.
- 승인 추천을 Queue에 연결해도 Queue 상태는 `PENDING_REVIEW`여야 합니다.
- 추천 승인 또는 Queue 연결만으로 Master Data 가격이 변경되면 안 됩니다.
- 고객용 화면에는 추천 센터 진입점과 추천 내부 데이터가 없어야 합니다.
- 이 기준은 `tests/rc-0-3-8-branch-stabilization.smoke.js`에서 반복 검증합니다.
