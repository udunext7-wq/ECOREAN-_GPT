# Report Generation Cycle

## Cycle

```text
Project Save File
-> Audience Filter
-> Report Template
-> Structured Report Data
-> JSON/Excel/PDF/HTML Export
-> Archive
```

## Report Audience

- 고객용: price and scope explanation
- 내부용: cost, margin, risk, source
- 대표 검토용: profit, cashflow, risk, approval
- 현장관리자용: schedule, work order, inspection
- 회계/재무용: payment, tax, settlement, cashflow
- AI 학습용: structured expected vs actual data
