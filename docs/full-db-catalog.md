# ECOREAN Full DB Catalog

## Purpose

This catalog defines what ECOREAN must collect before implementing the automatic estimate OS.

It does not contain real prices. It defines the total DB surface needed to operate a Korean interior Build Operation Center.

## Core Rule

Every catalog item must be easy to add, edit, archive, replace, and validate.

Each item is managed by:

- category
- subcategory
- itemName
- requiredDataFields
- sourceCandidates
- priority
- dataStatus
- owner
- updateCycle
- linkedSystems
- notes

## dataStatus

| Status | Meaning |
|---|---|
| EMPTY | No structure or data exists yet |
| STRUCTURE_READY | Schema exists but no real data |
| NEEDS_RESEARCH | Research target is defined |
| PARTIAL | Some real data exists |
| VERIFIED | Source-verified data exists |
| INTERNAL_VALIDATED | ECOREAN field data validated |

## Linked Systems

Each item must declare which systems it affects:

- Master DB
- Case Library
- Estimate Engine
- Schedule Engine
- Output Engine
- Storage
- Diagnostics
- Approval Log

## Catalog Domains

### 1. Process DB

Collect every work item required for actual project estimating, scheduling, purchasing, inspection, and defect tracking.

Included subcategories:

철거, 가설, 폐기물, 설비, 전기, 방수, 미장, 타일, 목공, 금속, 창호, 유리, 도어, 도장, 도배, 필름, 바닥재, 몰딩, 걸레받이, 가구, 주방, 욕실, 조명, 환기, 냉난방, 소방, 통신, 준공청소, 하자보수

### 2. Material DB

Collect main materials used in Korean interior work, including unit, spec, brand, waste rate, order unit, lead time, and linked process.

### 3. Accessory / Consumable DB

Collect small items that cause estimate leakage: adhesives, clips, spacers, protection, cutting consumables, screws, anchors, tapes, vinyl, and waste sacks.

### 4. Brand DB

Collect actual brands, product lines, model names, supply price, lead time, warranty, A/S, defect risk, installer preference, and alternative brands.

### 5. Labor / Productivity DB

Collect crew type, daily wage, minimum charge, productivity, aggregation rules, space factor, and preferred work scope.

### 6. Subcontract / Equipment / Logistics DB

Collect outsourced works and external costs such as ladder truck, lifting, waste disposal, freight, equipment rental, coring, cutting, and specialist subcontracting.

### 7. Schedule / Ordering DB

Collect duration, curing time, waiting time, predecessor/successor rules, lead time, delivery timing, and conflict conditions.

### 8. Risk / Defect DB

Collect defect types, causes, affected processes, prevention rules, inspection points, repair cost, recurrence rate, and responsible party.

### 9. Contract / Payment / Settlement DB

Collect contract payments, mid-payment triggers, final payment conditions, change order billing, subcontract settlement, material payment, tax invoice, receivables, and cashflow.

### 10. Operating Document DB

Collect all documents generated by the BOC: estimates, internal cost tables, purchase orders, daily reports, delivery checks, inspections, change approvals, defect sheets, cashflow, subcontract settlement, and handover checklist.

## Fill Order

Recommended fill sequence:

1. Process DB
2. Material and Accessory DB
3. Labor / Productivity DB
4. Brand DB
5. Schedule / Ordering DB
6. Subcontract / Equipment / Logistics DB
7. Risk / Defect DB
8. Contract / Payment / Settlement DB
9. Operating Document DB
10. Case Library validation

## Current Gap

The weakest current DB areas are:

- full process catalog outside bathroom
- labor productivity and minimum labor charge
- accessory/consumable leakage data
- subcontract and logistics price structure
- schedule and ordering lead time rules
- defect risk by brand/process/installer
- contract/payment/cashflow operating rules linked to schedule
