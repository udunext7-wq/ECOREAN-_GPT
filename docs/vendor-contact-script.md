| 동일 도기 타일 | 타일/도기 도소매 가능 여부 확인 | 타일 공급가, 납기, 현장 배송 |
| 방수닥터 | 방수재/방수 시공 협력 가능 여부 확인 | 도막/액체/탄성 방수재, 하자 책임 |
| 그라스텍 | 샤워부스/유리 파티션 공급 가능 여부 확인 | 샤워부스 제작가, 설치 포함 여부 |
| 성은창호그룹 | 창호 부분 교체 견적 가능 여부 확인 | KCC/LX급 창호, 실측, 납기, A/S |
| 진성창호 | KCC 창호 부분 교체 견적 확인 | 발코니/방 창호 부분 교체, 결로 대응 |
| 동양기업 | KCC E-MAX 창호 협력 가능 여부 확인 | 부분 교체 단가, 유리 사양, 납기 |
| 분당유리 | 복층/강화/파티션 유리 공급 확인 | 샤워부스 유리, 복층유리, 현장 시공 |
| 타워클린 | 실리콘/코킹 시공 협력 확인 | 바이오 실리콘, 창호 코킹, 하자 보증 |
| 한솔전기조명 | 전기자재/조명 공급 확인 | 다운라이트, 배선기구, 납기, 세금계산서 |
| 클린업 | 폐기물 처리 협력 확인 | 인테리어 폐기물 반출, 마대/차량, 처리확인 |

## 가격 문의 원칙

- 소비자가가 아니라 실제 공급가를 요청한다.
- 품목별 단가, 현장 배송비, 설치비, 부자재 포함 여부를 분리해서 받는다.
- 일회성 가격과 반복 거래 가격을 구분한다.
- 바로 Master DB에 반영하지 않고 Contact Log와 Approval Request로 보낸다.

## 하자/A/S 문의 원칙

- 제품 하자, 시공 하자, 운송 파손을 구분해서 책임 범위를 확인한다.
- 교환 가능 기간과 현장 재방문 가능 여부를 확인한다.
- 고객 클레임 발생 시 업체 대응 속도를 확인한다.
