# Vendor Interview Checklist

## Universal Questions

Ask every vendor:

- 실제 공급가는 얼마인가?
- 소비자가, 시장가, 공급가를 각각 구분할 수 있는가?
- 현장별 단가 조정이 가능한가?
- 최소 발주 단위는 무엇인가?
- 납기는 며칠인가?
- 급발주가 가능한가?
- 급발주 시 추가 비용이 있는가?
- 월말 정산이 가능한가?
- 선입금이 필요한가?
- 카드/현금/세금계산서 조건이 다른가?
- 파손 발생 시 교환 정책은 무엇인가?
- 하자 발생 시 책임 범위는 어디까지인가?
- A/S는 누가 처리하는가?
- 거래처가 추천하는 표준 브랜드는 무엇인가?
- 시공팀이 선호하는 브랜드는 무엇인가?
- 피해야 할 브랜드나 모델이 있는가?
- 최근 단가 변동이 있었는가?
- 다음 단가 인상 예정이 있는가?

## Tile Vendor Questions

- 벽타일, 바닥타일, 600각 포세린 공급가는?
- 박스 단위와 박스당 면적은?
- 최소 발주 수량은?
- 같은 로트 확보가 가능한가?
- 파손/로스 기준은?
- 대형타일/박판타일 납기는?
- 졸리컷 가공 가능 여부와 단가는?
- 배송비와 양중비는 별도인가?
- 반품 가능한가?

## Tile Accessory Questions

- 압착시멘트 포대당 단가는?
- 타일본드, 에폭시본드, 프라이머 공급가는?
- 아덱스급 또는 동급 접착재 추천 제품은?
- 레벨링 클립, 스페이서, 코너비드 단가는?
- 줄눈재와 에폭시 줄눈재 브랜드별 차이는?
- 제품별 권장 사용량은?

## Waterproof Vendor Questions

- 액체방수, 도막방수, 탄성방수, 우레탄 방수 공급가는?
- 제품별 커버리지는?
- 프라이머가 필요한가?
- 코너/배수구 보강재 포함 여부는?
- 양생시간은?
- 방수 하자 발생 시 제조사 또는 시공팀 책임 범위는?
- 추천 시공 방식은?

## Bathroom Fixture Questions

- 양변기, 세면기, 수전, 샤워수전 모델별 공급가는?
- 대림바스, 이누스, 계림, 아메리칸스탠다드 공급가 차이는?
- TOTO, Grohe, Hansgrohe 납기와 A/S는?
- 욕실장, 거울장, 슬라이드장 제작/기성 구분은?
- 샤워부스 실측 후 제작 기간은?
- 설치비 포함 여부는?
- 부속품 포함 여부는?

## Window / Glass Questions

- 부분 교체와 전체 교체 단가 기준은?
- 실측비가 별도인가?
- 철거비 포함인가?
- 프레임 종류별 공급가는?
- 일반 복층유리와 로이유리 차액은?
- 강화유리/접합유리 제작 납기는?
- 결로 보증 또는 클레임 책임 범위는?
- 실리콘, 우레탄폼, 백업재 포함 여부는?
- 방충망과 하드웨어 포함 여부는?

## Sealant / Caulking Questions

- 내부/외부 코킹 단가 기준은?
- m당 단가인가, 일당인가?
- 사용하는 실리콘 브랜드는?
- 바이오/무초산/우레탄 실란트 차액은?
- 하자 보증 기간은?
- 곰팡이/박리 발생 시 재시공 조건은?

## Waste Disposal Questions

- 마대, 1톤, 2.5톤, 5톤 기준 단가는?
- 상차 포함인가?
- 사다리차/양중 별도인가?
- 폐기물 종류별 단가가 다른가?
- 당일 처리 가능한가?
- 세금계산서 발행 가능한가?
