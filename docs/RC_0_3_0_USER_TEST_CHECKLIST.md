# RC-0.3.0 User Test Checklist

## 목적

LightBIM 도면 데이터가 BOC 견적, 실행, 고객 제안 출력까지 실제 사용 흐름으로 이어지는지 사용자 관점에서 검증한다.

## 시작 전 준비

- 테스트 빌드: `RC-0.3.0`
- 테스트 데이터: `tests/user-test-data/rc-0.3.0`
- LightBIM 입력 예시: `tests/fixtures/lightbim/real-minicad-export.lightbim.json`
- 앱에서 `RC-0.3.0 사용자 테스트` 화면을 열고 새 회차를 시작한다.
- 화면 캡처나 출력 파일은 각 단계의 증빙 경로로 기록한다.

## 실행 체크리스트

| 단계 | 검증 영역 | 사용자 작업 | 통과 기준 | 증빙 |
| --- | --- | --- | --- | --- |
| UT-01 | MiniCAD / LightBIM | 도면에서 LightBIM JSON 내보내기 | `ECOREAN.LightBIM.v0.1` JSON이 생성된다. | JSON 경로 |
| UT-02 | LightBIM Import | JSON 가져오기 | 공간 목록, 면적, 추천 견적 유형이 표시된다. | 화면 캡처 |
| UT-03 | 수량 검토 | 수량 한 항목 확인 또는 수정 | 수정 사유가 저장되고 재계산할 수 있다. | 화면 캡처 |
| UT-04 | 견적 / PCE | 견적 계산과 PCE 실행 | 도면 수량 기반 견적과 PCE 결과가 생성된다. | 결과 화면 |
| UT-05 | 계약 / 공정표 | 계약 초안과 공정표 생성 | 수량 기반 공기 산정 정보가 보인다. | 출력/화면 |
| UT-06 | 발주 / 입고 | 발주서 및 입고 기준 확인 | 할증 발주량과 기준 출처가 확인된다. | 발주 화면 |
| UT-07 | 실행 피드백 | 실제 사용량 입력 | 차이율과 상태가 계산된다. | 피드백 화면 |
| UT-08 | 추적 / 공간 맵 | 내부 추적과 공간 맵 확인 | 연결된 견적/발주/실사용이 공간별로 표시된다. | 공간 맵 |
| UT-09 | 고객 제안 | 고객 맵과 제안 보드 확인 | 고객 안전 모드 자료가 표시된다. | 보드 미리보기 |
| UT-10 | 출력 | PDF / Excel 내보내기 | 필요한 고객/내부 출력 파일을 열 수 있다. | 파일 경로 |
| UT-11 | 고객 안전 | 고객 화면 점검 | 원가, 마진, PCE, 발주, 차이 데이터가 보이지 않는다. | 점검 결과 |
| UT-12 | 마감 / 보정 | 프로젝트 마감 분석 확인 | 실행 피드백과 향후 보정 후보가 내부에 표시된다. | 화면 캡처 |

## 결과 기록 규칙

- `통과`: 기대 결과가 관찰되고 핵심 결함이 없다.
- `실패`: 작업은 가능하나 기대 결과가 어긋나거나 기능 결함이 있다.
- `차단`: 다음 단계를 진행할 수 없는 결함이나 환경 문제가 있다.
- 결함이 있는 단계에는 심각도와 증빙 경로를 기록한다.
- 모든 단계가 기록된 뒤 `테스트 판정 완료`를 선택한다.
