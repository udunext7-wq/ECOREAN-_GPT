# RC-0.3.0 초기 기준 데이터 세팅 가이드

## 목적

RC-0.3.0은 구조적으로 견적, PCE, 공정표, 발주, LightBIM 연결이 준비된 상태다.
이 문서는 실제 운영 전에 BOC가 바로 견적을 낼 수 있도록 초기 기준 데이터를 세팅하는 방법을 설명한다.

초기 기준 데이터는 최종 시장 단가가 아니다.

- 기본값
- 추정값
- 수정 필요

상태로 제공되며, 실제 업체 조건과 현장 기준에 맞게 반드시 수정해야 한다.

## 실행 전 백업

초기 세팅을 실행하기 전에는 현재 데이터를 먼저 백업한다.

앱에서:

1. `백업 / 복구 센터`를 연다.
2. `전체 백업 생성` 또는 `업데이트 전 백업 생성`을 실행한다.
3. 백업 이력에서 상태가 `정상`인지 확인한다.

`초기 기준 데이터 세팅` 화면에서 `백업 후 실행`을 누르면 세팅 전 백업을 먼저 생성한다.

실제 거래처 견적서나 매입 단가 확인 후 수정해야 한다.

## 표준 견적 품목

초기 표준 품목은 세 견적 유형에 맞춰 제공된다.

- 욕실 리모델링
- 주방 리모델링
- 전체 리모델링

각 품목은 다음 기준값을 가진다.

- 항목명
- 공정
- 기본 단위
- 기본 고객단가
- 기본 자재비
- 기본 노무비
- 기본 외주비
- 기본 마진율
- 적용 견적 유형
- 필수 여부
- 사용 여부
- 가격 상태
- source marker: `INITIAL_RC_0_3_0`

## 기본 패키지

초기 패키지:

- 욕실 기본형
- 욕실 표준형
- 욕실 고급형
- 주방 기본형
- 주방 표준형
- 주방 고급형
- 전체 기본형
- 전체 표준형
- 전체 프리미엄형

패키지는 견적 시작을 빠르게 하기 위한 구성 묶음이며, 고객 제안 전 실제 옵션과 금액을 검토해야 한다.

## 단가 수정 방법

1. `기준 데이터 관리` 화면을 연다.
2. 공정, 자재, 인력, 장비, 표준 품목 중 수정할 유형을 선택한다.
3. 실제 단가와 업체 조건에 맞게 JSON 값을 수정해 저장한다.
4. `데이터 검증`을 실행한다.
5. `수정 필요` 단가가 줄었는지 확인한다.

## 업체 정보 입력 방법

업체 마스터는 실제 거래처 정보가 필요하므로 자동으로 임의 업체를 확정하지 않는다.

입력 권장 항목:

- 업체명
- 업체 유형
- 담당 공정
- 연락처
- 지역
- 결제 조건
- 신뢰도 점수
- 비고

## 운영 전 필수 확인

- 공정 마스터가 비어 있지 않은지 확인
- 자재 마스터가 비어 있지 않은지 확인
- 표준 견적 품목이 비어 있지 않은지 확인
- 단위가 누락된 항목이 없는지 확인
- 고객 단가가 0 이하인 품목이 없는지 확인
- 마진율이 0 이하인 품목이 없는지 확인
- `NEEDS_UPDATE` 단가를 실제 조건에 맞게 수정
- 업체 정보를 실제 거래처 기준으로 입력
- 백업이 정상 생성되었는지 확인

## 주의사항

- 초기 단가는 시장 검증 가격이 아니다.
- 외부 시세 크롤링은 포함하지 않는다.
- 기존 사용자가 수정한 데이터는 기본 실행에서 덮어쓰지 않는다.
- 초기 seed는 idempotent하게 동작하며 반복 실행해도 중복을 만들지 않는다.
- 실제 운영 전 백업을 생략하지 않는다.
