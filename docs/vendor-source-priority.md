# Vendor Source Priority

## Priority 1: Official Website

Use first when available.

Why:

- highest control by vendor
- public business contact
- service details
- current branding

## Priority 2: Supplier or Brand Dealer Pages

Examples:

- KCC 대리점
- 노루페인트 대리점
- brand dealer locator

Why:

- brand relationship can be verified
- handled products are clearer

## Priority 3: Public Directory

Use cautiously.

Examples:

- business directories
- public company databases
- job posting company profiles

Rule:

- mark as `NEEDS_VERIFICATION`
- verify by phone before Vendor Master registration

## Priority 4: Map Search

Use for discovery only.

Do not treat map data as verified Vendor Master data until manual contact.

## Priority 5: Manual Input

Use when CEO already knows the vendor.

Manual input still needs:

- contact log
- current relationship status
- supplier price evidence
- CEO approval for Master DB impact

## TOP 30 Contact Ranking

Rank by:

1. category priority for current project
2. region fit
3. public source confidence
4. wholesale possibility
5. installation capability
6. defect risk reduction potential
7. lead time impact
8. payment condition importance
