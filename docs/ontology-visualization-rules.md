# Ontology Visualization Rules

## 1. 목적

이 문서는 ECOREAN 온톨로지 그래프를 시각화할 때의 규칙을 정의한다.

목표는 대표님, 관리자, AI 에이전트가 다음을 눈으로 확인할 수 있게 하는 것이다.

- 공정 누락
- 자재 연결
- 부자재 누락
- 인력 투입 관계
- 공정 선후행
- 일정 충돌
- 실제 결과와 예상값의 오차
- 승인 대기 항목

## 2. 시각화 기본 원칙

```text
1. 공정은 중심 노드로 표시한다.
2. 공간은 공정의 적용 조건으로 표시한다.
3. 자재/부자재는 공정 아래에 연결한다.
4. 인력은 공정별 통합 계산 기준으로 연결한다.
5. 단가는 별도 Price 노드로 분리한다.
6. 실제 현장 데이터는 Case 노드로 연결한다.
7. 승인 필요 항목은 시각적으로 강조한다.
```

## 3. 노드 색상 규칙

```text
Space: 파랑
Process: 금색
Material: 초록
AccessoryMaterial: 연두
LaborRole: 보라
Equipment: 회색
Option: 주황
Condition: 분홍
Price: 노랑
Schedule: 청록
Case: 흰색
Risk: 빨강
OutputDocument: 검정/남색
```

## 4. 관계선 규칙

```text
REQUIRES: 실선
PRECEDES: 방향 화살표
FOLLOWS: 방향 화살표
DEPENDS_ON: 굵은 화살표
USES: 점선
HAS_OPTION: 얇은 실선
AFFECTS_PRICE: 노랑 선
AFFECTS_LABOR: 보라 선
AFFECTS_DURATION: 청록 선
CONFLICTS_WITH: 빨강 점선
APPLIES_TO_SPACE: 파랑 선
AGGREGATES_WITH: 굵은 초록 선
HAS_MINIMUM_LABOR: 보라 굵은 선
GENERATED_FROM: 회색 화살표
COMPARED_WITH_ACTUAL: 빨강/초록 비교선
NEEDS_APPROVAL: 빨강 굵은 테두리
```

## 5. 공정 중심 뷰

공정 하나를 선택하면 다음이 펼쳐져야 한다.

```text
적용 공간
선행공정
후행공정
필요 자재
필요 부자재
필요 인력
장비
옵션
가격 출처
최소 품수
묶음 계산 대상
리스크
출력 문서
실제 사례
```

## 6. 공간 중심 뷰

공간 하나를 선택하면 다음이 보여야 한다.

```text
해당 공간에 적용 가능한 공정
실제 선택된 공정
자동 포함된 공정
누락 의심 공정
공간별 난이도 보정
고객용 견적 표시 항목
내부 원가 통합 항목
```

## 7. 견적 진단 뷰

견적 하나를 선택하면 다음을 표시한다.

```text
선택된 공정
자동 포함 공정
조건부 포함 공정
누락 의심 공정
승인 필요 항목
낮은 신뢰도 단가
최소 품수 적용 항목
공정별 통합 인건비
공간별 고객 견적 분배
```

## 8. Case 비교 뷰

실제 현장 사례와 비교할 때 표시한다.

```text
예상 견적
실제 원가
차이 금액
차이 비율
오차 원인
재발 가능성
다음 견적 보정 추천
승인 필요 여부
```

## 9. 승인 시각화 규칙

AI 또는 시스템이 다음을 제안하면 반드시 승인 대기 상태로 표시한다.

```text
단가 변경
마진 변경
표준사양 변경
공정 자동 포함 규칙 변경
최소 품수 기준 변경
spaceFactor 변경
ML 보정값 적용
```

## 10. 그래프 화면 최소 기능

초기 시각화 도구는 다음 기능을 가져야 한다.

```text
노드 검색
공정 코드 검색
공간별 필터
관계 유형 필터
승인 대기 필터
리스크 필터
단가 신뢰도 필터
Case 비교 보기
```
