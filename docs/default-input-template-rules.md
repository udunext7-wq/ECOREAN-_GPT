# Default Input Template Rules

## Purpose

Default input templates make repeated project input faster.

They are not estimates. They are starting input patterns.

## Template Use

```text
buildingType + areaRange + projectType
-> suggested spaceComposition
-> default finish/budget/scope
-> confirmationFields
```

## Required Separation

- requiredFields must be entered or imported
- optionalFields may remain empty
- confirmationFields must be checked before estimate finalization

## Example

A 24 pyeong apartment template may suggest:

- bathroomCount=1
- roomCount=2 or 3
- balconyCount=1
- kitchenType=standard
- confirmationFields: demolitionScope, windowScope, waterproofLayer, condensationCause
