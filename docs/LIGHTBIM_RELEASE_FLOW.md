# LightBIM + BOC Release Flow

## 목적

RC-0.3.0은 MiniCAD에서 생성한 공간 데이터를 BOC의 견적과 실행, 고객 제안 자료까지 안정적으로 이어 주는 릴리스입니다. LightBIM은 가격을 계산하지 않고, 공간과 수량의 근거를 제공합니다. 가격과 수익성 판단은 BOC가 담당합니다.

## 1. MiniCAD에서 내보내기

1. MiniCAD에서 도면을 작성합니다.
2. `LightBIM JSON 내보내기`를 실행합니다.
3. 결과 파일은 `ECOREAN.LightBIM.v0.1` 스키마로 공간, 벽체, 개구부, 수량, BOC 견적 입력 힌트를 포함합니다.

개발 환경의 LightBIM 관련 산출물 기준 경로는 `export/lightbim`이며, 패키지 앱에서는 Electron `userData/export/lightbim`을 사용합니다.

## 2. BOC에서 가져오기

1. `LightBIM 도면 가져오기`에서 JSON 파일을 선택합니다.
2. 프로젝트명, 공간 목록, 수량 요약과 추천 견적 유형을 확인합니다.
3. 욕실, 주방 또는 전체 리모델링 견적 초안을 생성합니다.

잘못된 JSON이나 공간이 없는 데이터는 사용자용 오류 문구로 안내하며 기존 수동 견적 입력은 계속 사용할 수 있습니다.

## 3. 수량 검토와 견적 / PCE

`LightBIM 수량 검토`에서 도면 수량을 확인하고 필요 시 사유와 함께 수정합니다.

- 확인된 LightBIM 수량은 견적 항목 수량으로 사용됩니다.
- 사용자 수정 수량은 LightBIM 원본보다 우선합니다.
- 견적 금액과 원가는 BOC 견적 엔진이 계산합니다.
- 수량 변경 후 PCE가 다시 실행되어 수익성 결정을 갱신합니다.

## 4. 공정표와 발주

확정된 수량은 공정표의 기간 산정과 발주 기준으로 연결됩니다.

- 공정표는 타일, 도배, 바닥, 천장 등 공정별 생산성 기준으로 기간을 산정합니다.
- 발주서는 기준 수량과 품목별 할증률을 적용해 발주 수량을 생성합니다.
- 입고 기록은 발주 수량을 기준으로 부족 여부를 확인합니다.

## 5. 입고, 실사용 피드백, 보정

`LightBIM 실행 피드백`은 다음 수량 흐름을 비교합니다.

`도면 수량 -> 검토 수량 -> 발주 수량 -> 입고 수량 -> 실제 사용 수량 -> 차이 / 잔량`

차이가 큰 항목은 다음 견적 또는 발주 할증률 보정 후보가 되며, 승인 없이 자동 적용되지 않습니다.

## 6. 추적 보기와 내부 공간 맵

- `LightBIM 추적 보기`는 도면 수량이 견적, 공정표, 발주, 입고, 실사용, 보정 후보로 연결된 경로를 보여 줍니다.
- `LightBIM 공간 맵`은 공간을 클릭하여 해당 공간의 내부 추적 상태와 검토 필요 여부를 확인하는 운영 화면입니다.

이 화면들은 내부 관리용이며 고객에게 공개하지 않습니다.

## 7. 고객용 공간 맵과 제안 보드

- `고객용 공간 제안 맵`은 공간 구성, 공사 범위, 진행 상태, 승인된 제안 이미지만 표시합니다.
- `디자인 보드 생성`의 고객 제안 보드는 공간 맵, 공간별 공사 범위, 디자인 방향, 승인 이미지, 견적 요약을 PDF 구성에 포함할 수 있습니다.

고객용 PDF/화면에는 내부 수량 근거, 발주/입고, 실사용 차이, 원가, 마진, PCE 또는 보정 정보를 포함하지 않습니다.

## 8. 데이터 분리 원칙

고객에게 표시 가능한 정보:

- 공간명과 공간 면적
- 고객용 공사 범위
- 공개 진행 상태
- 승인된 제안 이미지
- 고객용 견적 합계와 결제 안내

내부 전용 정보:

- 원가, 마진, 수익, PCE
- 업체, 인력, 발주, 입고 정보
- 실제 사용량, 손실, 차이 분석
- 보정 규칙, 위험 점수, RED ALERT

## 9. 한계

- 외부 DWG/DXF 자동 파싱은 포함되지 않습니다.
- 전체 BIM 객체 편집기와 3D 모델링은 포함되지 않습니다.
- 실시간 다중 사용자 협업은 지원하지 않습니다.
- 회계/은행 이체 연결은 지원하지 않습니다.
- ComfyUI 시각화는 사용할 경우 로컬 서버가 필요합니다.
- 고객 포털 공유 링크는 현재 로컬 토큰 placeholder입니다.

## 10. 릴리스 검증

주요 릴리스 검증은 `tests/lightbim-boc-release-flow.smoke.js`와 `tests/lightbim-customer-safety-regression.smoke.js`가 담당합니다. 전체 release smoke는 이 두 흐름을 포함해 기존 LightBIM 및 BOC 회귀 검사를 함께 실행합니다.
