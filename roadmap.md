# ECOREAN Roadmap

## Phase 1: Foundation

Goal: Turn founder logic into documents, data structures, and repeatable workflows.

- Define company operating doctrine
- Define BOC concept
- Define estimate input and output structure
- Define standard construction process categories
- Define cost, margin, labor, and material tables

## Phase 2: Interior Automated Estimation OS

Goal: Build the first usable operating module.

- Create input form
- Create estimate generation logic
- Create internal cost sheet
- Create process-level margin table
- Create material order table
- Create labor deployment table
- Create schedule generation logic
- Export customer-facing PDF or document

## Phase 3: Admin Dashboard

Goal: Convert estimation into operational control.

- Project dashboard
- Customer/project database
- Estimate version management
- Cost and margin tracking
- Site progress tracking
- Material order status
- Labor allocation view

## Phase 4: AI Executive Layer

Goal: Add AI agents that assist judgment and execution.

- Strategy AI
- Estimate and Design AI
- Site Management AI
- Marketing AI
- Automation Development AI
- Finance AI
- Research AI

## Phase 5: Replication System

Goal: Make the operation teachable, transferable, and franchisable.

- Standard operating procedures
- Role manuals
- Training system
- Quality control system
- Partner/franchise package
- Performance dashboards

## Phase 6: Vertical Expansion

Goal: Expand beyond interior construction.

- Human management
- Modular housing
- Franchise structure
- Real estate development
- Investment and capital operation
