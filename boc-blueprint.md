# Build Operation Center Blueprint

## Definition

BOC, or Build Operation Center, is the central operating system for ECOREAN.

It begins as an Interior Automated Estimation OS and gradually expands into a full company control system.

BOC should connect sales, estimation, design, cost control, site execution, labor deployment, material purchasing, finance, and strategic decision-making.

## First MVP: Interior Automated Estimation OS

The first version should focus on turning minimal project inputs into complete execution documents.

### Minimum Input

- Project type
- Space type
- Area
- Region
- Construction scope
- Finish grade
- Major material choices
- Site constraints
- Desired schedule

### Core Outputs

- Customer estimate
- Internal cost table
- Margin table by process
- Material quantity sheet
- Material order sheet
- Construction schedule
- Labor input plan
- Site checklist
- Cash flow summary

## Design Principle

Every BOC function must answer three questions:

1. What decision does this system make easier?
2. What human dependency does this reduce?
3. Can this process be repeated by another person with the same result?
